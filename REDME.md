# LLM and Generative AI Portfolio

Lab work for PUSL 3205 - Large Language Models and Generative AI.

## Labs
- [Lab 1: Sentiment Analysis Using Traditional Machine Learning](lab-01-sentiment-analysis): text preprocessing, Bag of Words, Logistic Regression and SVM on the UCI sentiment dataset
- [Lab 2: AI in Everyday Challenges](lab-02-everyday-challenges): Group 6, The Plastic Problem. Product concept, features and app mock-up for BringIt, designed with an LLM as a development partner
- [Lab 3: Tiny Transformer Language Model](lab-03-tiny-transformer): a GPT-style Transformer built in PyTorch and trained on TinyStories, with loss curves, perplexity, experiments and generated stories

## Tools
Python, Pandas, NumPy, Scikit-learn, PyTorch, Matplotlib, Jupyter
